# My Web Development Classwork

Hi! I'm Sahara Nagarkoti, and this is a small collection of HTML and CSS pages I made while learning web development in class.

## Files Included

- `home.html` - A basic homepage with a navbar, banner, and product cards.
- `login.html` - A simple login form.
- `register.html` - A registration form with inputs for name, gender, interests, email, password, and date of birth.
- `practice.html` - My HTML basics practice page with headings, lists, links, and a striped table.
- `style.css` - The stylesheet shared across the pages.

## What I Practiced

- HTML tags (headings, lists, tables, forms, links)
- Linking an external CSS file
- Flexbox and CSS Grid for layout
- Styling forms, buttons, shadows, and hover effects

Still learning and improving as I go!
